# 💻 Terminal Portfolio | Mohammad Hossein Yazdanfar

Welcome to my very first GitHub project! 🎉

This is an interactive, hacker-style command-line interface (CLI) script built with Python. It acts as my digital resume, showcasing my background as a Computer Engineering student, my programming skills, and my interests in a fun, retro terminal format.

## ✨ Features
- ⌨️ Retro typewriter text effect
- 🎨 Custom ASCII Art
- 🎮 Interactive navigation menu to explore my resume
- 🌈 Colorized terminal output (Windows/Linux/Mac compatible)
